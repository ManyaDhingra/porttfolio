# Personal Portfolio Website 🌐

A responsive and modern personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This website showcases my skills, projects, achievements, and contact information in a clean and user-friendly interface.

## Features

- Responsive design for all devices
- Modern and intuitive UI
- About Me section
- Skills showcase
- Projects portfolio
- Contact section
- Smooth scrolling and interactive elements
- Fast and lightweight performance

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```text
portfolio-website/
│
├── index.html
├── style.css
├── script.js
├── images
└── README.md
```

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
```

### Run Locally

Simply open the `index.html` file in your browser.

Alternatively, use VS Code's Live Server extension:

```bash
Right Click → Open with Live Server
```
